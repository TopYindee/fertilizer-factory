## 4. วิธีใช้งานมาตรฐานทุกหน้า Master Data
ทุกหน้าใช้โครงเดียวกัน (Action Bar + ตาราง + Modal):
1) **ค้นหา**: พิมพ์ในช่องค้นหา → กรอง filteredItems ทันที
2) **เพิ่ม**: ปุ่ม `+ เพิ่ม...` มุมขวา → Modal ฟอร์มขึ้นมา รหัสจะรันต่ออัตโนมัติ VEND-004, CUST-004, RM-006, FG-006, PKG-004 แบบreadonlyสีเทา (`this.$set` ให้ขึ้นรอทันที)
3) **แก้ไข**: กดไอคอนปากกา (น้ำเงิน) ท้ายแถว → ฟอร์มเติมค่ามาให้
4) **ลบ**: กดถังขยะแดง → Modal แดง "ยืนยันการลบ" → ยืนยันถึงลบ + Toast เขียวกลางบน "ลบสำเร็จ"
5) **ส่งออก**: ปุ่ม `ส่งออก` (fa-file-excel) ข้างปุ่มเพิ่ม → โหลด CSV พร้อม BOM ภาษาไทย (`\uFEFF`) ตามที่กรองอยู่ ไฟล์ชื่อ `vendors-2026-09-23.csv`
6) **บังคับกรอก**: ฟิลด์ * สีแดง ถ้าว่างขอบจะแดง bg-red-50 + Toast แดง "กรุณากรอก ..." + focus ช่องแรก
> เคล็ดลับ: ส่งออกจะเอาเฉพาะที่เห็นหลังค้นหา - ค้นหา "YARA" แล้วส่งออกจะได้แค่ YARA

## 5. ข้อมูลบริษัท
- ฟิลด์: **ชื่อไทย*** / ชื่ออังกฤษ / สาขา (dropdown: สำนักงานใหญ่, สาขา 2, สาขา 3 ดีฟอลต์ `สำนักงานใหญ่` ขึ้นรอ) / เลขผู้เสียภาษี / ที่อยู่ (textarea)
- เพิ่ม: ใส่ชื่อไทย + สาขาขึ้นรอ → บันทึก → Toast เขียว
- แก้ไข: กดปากกา → แก้แล้วบันทึก
- ตัวอย่าง: บริษัท เวิลด์ เฟอท จำกัด / 105531024397 / 933 ถนนมหาไชย

## 6. ปีการผลิต
- ฟิลด์: **รหัสปี*** (เช่น 2026, placeholder) / **วันเริ่ม*** (type=date dd/mm/yyyy) / **วันจบ*** (type=date) / สถานะ (เปิด/ปิด ดีฟอลต์ `เปิด` ขึ้นรอ)
- ทั้ง 3 ช่อง * ต้องกรอกครบ (เราเพิ่ม start_date, end_date เป็นบังคับ) ถ้าว่างจะแดงเตือน
- วันเริ่ม-จบใช้เลือกจากปฏิทิน ไม่ต้องพิมพ์
- ใช้กำหนดขอบเขตผลิตแต่ละปี

## 7. ตั้งค่าโกดังแบบ Zone
1) เลือก **ประเภทโกดัง**: วัตถุดิบ(แม่ปุ๋ย)/สินค้าFG/บรรจุภัณฑ์PKG → รหัสหลักจะรัน WH-RAW-002 / WH-FG-001 / WH-PKG-001 อัตโนมัติ (readonly สีเทา)
2) ใส่ **จำนวนโซนย่อย** 1-10 (ลบ 1 ได้, พิมพ์ว่างได้ตอนพิมพ์, blur ถึง clamp 1-10) → ช่องปริมาณจะโผล่ตามจำนวน (Z01, Z02...)
   - โฟกัสแล้ว `select()` พิมพ์ทับได้เลย ไม่เป็น 02, ถ้าว่างจะ placeholder 0
3) ใส่ **ปริมาณต่อโซน**: โฟกัสแล้ว select() พิมพ์ทับ, หน่วย: วัตถุดิบ/FG โชว์ `ตัน (กระสอบ 50กก.)` = ตัน*20, บรรจุภัณฑ์โชว์ `ใบ`
4) กดบันทึก → สร้างหลายแถว (1 แถวต่อ 1 โซน) พร้อม code_id = ID-xxxxx
> คำเตือน: ลดจำนวนโซน ปริมาณโซนที่เกินจะหาย - เช็คให้ดีก่อนบันทึก / zoneCount เริ่มต้น 1 มี Z01 รอเลย

## 15. เคล็ดลับใช้งานทั่วไป
- รหัสที่รันต่อใช้ `$set` ให้ขึ้นรอทันที ไม่ต้องคลิกฟิลด์ก่อน
- ช่องตัวเลข placeholder 0 จะว่างให้เห็น 0 จางๆ พิมพ์ทับได้เลย ไม่เป็น 02 (ใช้ :value + @input + @blur)
- ช่องจำนวนโซน ลบ 1 ได้, พิมพ์ว่างได้ตอนพิมพ์ (updateZones อนุญาตว่าง)
- กด `พิมพ์` ในหน้าคู่มือจะ Print → Save as PDF ได้ทันที (Word ให้เปิด HTML แล้ว Save as DOCX)
- รองรับ Mobile / Tablet / Desktop, เมนูมี backdrop ดำ, Toast กลางบนเด่น
